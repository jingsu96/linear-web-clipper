Linear Web Clipper does not collect, transmit, or store any user data on external servers. All configuration data remains on your device. The extension communicates only with services you explicitly configure—namely, Linear and your chosen AI provider(s).

1. Scope

This Privacy Policy governs the collection, use, and disclosure of information by the Linear Web Clipper browser extension (the “Extension”). By installing or using the Extension, you acknowledge that you have read and understood this policy.

2. Information We Do Not Collect

The Extension does not collect any personally identifiable information or behavioral data. Specifically, the Extension:

  • Does not collect personal information or user identifiers
  • Does not collect usage statistics, analytics, or telemetry
  • Does not deploy cookies, tracking pixels, or similar technologies
  • Does not transmit any data to the developer or any first-party servers
  • Does not monitor or record browsing activity

3. Locally Stored Data

The Extension stores configuration data exclusively on your device using the Chrome Storage API. This data never leaves your browser unless transmitted to a service you have configured as described in Section 4.

3.1 Data Stored Locally

  • Linear API key — required to authenticate with your Linear workspace
  • AI provider API keys — stored only if you optionally configure one or more AI providers
  • User preferences — default team, project, label assignments, and AI provider priority order
  • Extension settings — auto-summarization preferences and metadata display options

3.2 Data Retention and Deletion

Locally stored data persists until you take one of the following actions: (a) uninstall the Extension, (b) clear the Extension’s storage via browser settings, or (c) reset settings within the Extension’s options page. No data survives uninstallation.

3.3 Security of Stored Data

  • API keys are encrypted via Chrome’s built-in storage encryption
  • Data is sandboxed and inaccessible to other extensions or websites
  • No data leaves your device except as described in Section 4

4. Data Transmission to Third-Party Services

The Extension transmits data only to services that you explicitly configure with your own API credentials. All transmissions occur over encrypted HTTPS/TLS connections.

4.1 Linear (Required)

4.2 AI Providers (Optional)

If you choose to enable AI-powered summarization, the Extension will transmit page content to your selected AI provider(s) for processing. You may configure one or more of the following providers; when multiple providers are configured, they are attempted in your specified priority order.

Important: AI features are entirely optional and disabled by default. No content is transmitted to any AI provider unless you have explicitly provided an API key and initiated a summarization request.

4.3 Data Not Transmitted

Under no circumstances does the Extension transmit the following:

  • Browsing history or navigation patterns
  • Personal or demographic information
  • Usage analytics, diagnostics, or telemetry
  • Data to the Extension developer or any first-party infrastructure

5. Permissions

The Extension requests only the browser permissions necessary for its core functionality. Each permission and its justification is detailed below.

Permission Purpose Scope of Access
sidePanel Render the clipper interface UI presentation only; no data access
activeTab Read the current page for clipping Active tab only, upon user action
storage Persist API keys and preferences Local browser storage only
scripting Extract page content and metadata Active tab only, upon user action
<all_urls> Enable clipping from any website Only pages you explicitly choose to clip

6. Security

The Extension implements the following measures to protect your data:

  • All API keys are encrypted via Chrome’s built-in storage mechanism
  • All network communication uses HTTPS with TLS encryption
  • No data is logged, recorded, or retained by the developer
  • The Extension does not execute remote code or load external scripts
  • No third-party analytics, advertising, or tracking SDKs are embedded
  • Source code is publicly available for independent security audit

7. Your Rights

Because the Extension does not collect or store personal data on any external server, traditional data-subject rights (such as those under GDPR or CCPA) are inherently satisfied. You retain full control over all data associated with the Extension:

  • Access — View all stored data through the Extension’s settings page
  • Deletion — Remove all data by uninstalling the Extension or clearing its storage
  • Portability — Your API keys and preferences are accessible in browser storage
  • Consent withdrawal — Disable or remove AI features at any time without affecting core functionality
  • Transparency — Review the complete source code on GitHub

8. Children’s Privacy

The Extension is not directed at individuals under the age of 13. The Extension does not knowingly collect personal information from children. If you believe a child has provided information through the Extension, please contact us using the information in Section 12.

9. International Considerations

As the Extension processes data exclusively on your local device, no cross-border data transfer occurs by virtue of the Extension itself. However, when you transmit data to third-party services (Linear, AI providers), such data may be processed in jurisdictions where those providers operate. Please consult the respective provider’s privacy policy for details on their data-processing locations and safeguards.
