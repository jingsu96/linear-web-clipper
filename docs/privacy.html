Privacy Policy for Linear Web Clipper

Last Updated: February 12, 2026
Extension Name: Linear Web Clipper
Developer: Jinghuang Su

Quick Summary

We don't collect your data. Everything stays on your device or goes directly to the services you configure (Linear and optional AI providers). No tracking, no analytics, no data collection by the developer.

1. Data Collection

We do not collect any user data. This extension:

  • ❌ Does not collect personal information
  • ❌ Does not collect usage statistics or analytics
  • ❌ Does not collect telemetry data
  • ❌ Does not use tracking technologies (cookies, beacons, etc.)
  • ❌ Does not transmit any data to the developer

2. Local Data Storage

All data is stored locally on your device using Chrome's secure storage API:

What is stored locally:

  • Linear API key - Encrypted by Chrome's storage API
  • AI provider API keys - If configured (encrypted by Chrome); you may configure multiple providers
  • User preferences - Default team, project, AI provider selection and priority order
  • Settings - Auto-summarization preferences, metadata options

Data retention:

  • Data persists until you uninstall the extension or manually clear it
  • Delete data by uninstalling the extension or clearing settings

Security:

  • ✅ All API keys encrypted by Chrome's built-in storage
  • ✅ Data never accessible to other extensions or websites
  • ✅ Data never leaves your device (except as described below)

3. Data Transmission

The extension transmits data only to the services you explicitly configure:

Linear API (Required)

  • What is sent: Issue title, description (page content), team ID, project ID
  • Purpose: Create issues in your Linear workspace
  • When: Only when you click "Create Issue"
  • Privacy Policy: https://linear.app/privacy

AI Providers (Optional)

You can optionally configure one or more AI providers for content summarization. When multiple providers are configured, they are tried in your chosen priority order:

Provider Purpose Privacy Policy
OpenAI Generate summaries, reformat transcripts OpenAI Privacy
Anthropic Claude Generate summaries, reformat transcripts Anthropic Privacy
Google Gemini Generate summaries, reformat transcripts Google Privacy
DeepSeek Generate summaries, reformat transcripts DeepSeek Privacy
Grok (xAI) Generate summaries, reformat transcripts xAI Privacy
Groq Generate summaries, reformat transcripts Groq Privacy
Mistral AI Generate summaries, reformat transcripts Mistral Privacy
OpenRouter Generate summaries, reformat transcripts (routes to various AI models) OpenRouter Privacy
Note: AI features are completely optional. You must explicitly provide an API key to enable them. No content is sent to AI providers unless you actively use these features.

What is NOT transmitted:

  • ❌ Your browsing history
  • ❌ Personal information
  • ❌ Usage analytics or telemetry
  • ❌ Any data to the extension developer
